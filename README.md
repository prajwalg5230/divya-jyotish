## 🚀 How to Run the Application

### Option 1: Using the Quick Launcher
```bash
cd /data/data/com.termux/files/home
./start_astro_app.sh
```

### Option 2: Direct Python Server
```bash
python3 /data/data/com.termux/files/home/divya_astro_app/server.py
```

Then open your browser (Chrome / Edge / Firefox) and visit:
👉 **`http://localhost:8080`** (or your local IP on mobile).
